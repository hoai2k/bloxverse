About

A browser voxel sandbox inspired by the block game everyone knows. Survival, Creative, Hardcore, Adventure and Spectator modes; three dimensions; biomes, caves, ores, villages, mobs, farming, crafting, smelting, weather, day/night and more. Everything, including all textures and sounds, is generated in code at runtime — no assets, no build step.

Controls: WASD move · Space jump · Shift sneak · Ctrl/double-W sprint · E inventory · Q drop · T chat · / command · F3 debug · F5 view · Esc pause · 1-9 hotbar · scroll to select · F fishing... just kidding, F swaps to offhand.
